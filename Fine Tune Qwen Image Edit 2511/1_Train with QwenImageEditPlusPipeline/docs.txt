✅ STEP 1: Install uv (Official method)
Run this in terminal:
curl -LsSf https://astral.sh/uv/install.sh | sh


✅ STEP 2: Add to PATH
Ubuntu does NOT automatically add ~/.local/bin to PATH in a new install.
Run:
echo 'export PATH="$HOME/.local/bin:$PATH"' >> ~/.bashrc
source ~/.bashrc
